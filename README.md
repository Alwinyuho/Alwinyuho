## Featured project

### SemCAT — Semantic Correlation for Agentic Threat Detection

SemCAT explores how related security alerts can be grouped into candidate incidents. It compares a shared-entity and time-window baseline with an optional text-embedding approach. The project includes a Python correlation core, a Streamlit analyst dashboard, and optional network and domain detector demonstrations.

**Tools:** Python · Streamlit · scikit-learn · sentence-transformers

The bundled examples are illustrative; their metrics are not real-world benchmark results.
